# Trench Crusade — Калькулятор кубиков

Оффлайн веб-приложение для расчёта вероятностей броска в настольной игре Trench Crusade.
Открывается на телефоне и на ПК, работает без интернета, устанавливается как PWA.

## Правила броска

Базовый бросок — 2d6, успех при сумме **7 и выше**.

Модификаторы:

| Модификатор | Эффект |
|---|---|
| ±1 кубик к броску | бросается `2 + \|нетто\|` кубов |
| ±1 к результату | прибавляется к сумме кубов |
| +1 кубик в сумму | добавляет и кубик, и место в сумме |

- Нетто по кубам **положительное** — суммируются **лучшие** кубы, **отрицательное** — **худшие**.
- Бросается всегда минимум 2 куба.
- «Кубик в сумму» — отдельная ось: `K = 2 + S` суммируемых, `N = K + |D|` бросаемых.

Криты (отключаются тумблером):

- сумма учтённых кубов **12 и выше** — автоуспех;
- сумма учтённых кубов **2 и ниже** — автопровал;
- считаются **до** плоского модификатора.

## Возможности

- Точный расчёт перебором всех исходов (не симуляция).
- Процент успеха закреплён внизу экрана.
- Панель «что даст ещё один модификатор» — итоговый процент и разница в п.п.
- Серия бросков: шанс «N и больше успехов», среднее число успехов.
- Реальный бросок кубов с подсветкой учтённых и отброшенных.
- Именованные пресеты конфигураций.
- Распределение суммы и таблица «шанс выбросить X+».

## Запуск

Локально — открыть `index.html` в браузере.

Для установки на домашний экран телефона нужен http(s). Локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть `http://<IP-компьютера>:8000` с телефона в той же сети.

## Состав

- `index.html` — всё приложение: расчёт, вёрстка, логика
- `manifest.webmanifest` — метаданные PWA
- `sw.js` — service worker для оффлайн-кеша
